┌─────────────────────────────────────────────────────────────────────────────┐
│                         AUTOMATIC CALCULATIONS                              │
└─────────────────────────────────────────────────────────────────────────────┘

Hours Worked = (Time Finished - Time Started) / 60 minutes
              ↓
Cost = Hours × Staff Cost Rate (e.g., 5 hours × $35/hr = $175)
              ↓
Revenue = Hours × Client Billing Rate (e.g., 5 hours × $95/hr = $475)
              ↓
Profit = Revenue - Cost (e.g., $475 - $175 = $300)

All calculated automatically in reports!

END OF MONTH:
  13. Accountant goes to Reports

┌─────────────────────────────────────────────────────────────────────────────┐
│                         QUICK START COMMANDS                                │
└─────────────────────────────────────────────────────────────────────────────┘

1. Setup database in SQL Server Management Studio:
   - Open and run: database/schema.sql
   - Open and run: database/reports.sql

2. Configure application:
   - Create .env file from ENV_TEMPLATE.txt
   - Set your DB credentials

3. Install and run:
   cd D:\timetrack
   npm install
   npm start

4. Open browser:
   http://localhost:3000

That's it! You're running! 🚀
